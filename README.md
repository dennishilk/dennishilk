## 🚀 Featured right now

### 🖥️ [BoringOS](https://github.com/dennishilk/boringos) — an independent desktop OS from scratch

BoringOS is an experimental **x86_64 operating system with its own kernel, BoringKernel**, its own future userspace and a native BoringWM desktop stack. It is not a Linux or BSD distribution and is written primarily in **C**.

Current work is happening in QEMU and already spans the low-level path from memory management and interrupts through processes, Ring 3, syscalls, ELF userspace, a native C runtime, serial-console I/O, VFS and filesystem work.

> **boring is not a bug.**  
> **it's the entire operating system now.**

[Repository](https://github.com/dennishilk/boringos) · [Roadmap](https://github.com/dennishilk/boringos/blob/main/docs/roadmap.md)

### 🐧 [Linux Migration Companion](https://github.com/dennishilk/linux-migration-companion) — test Linux before replacing Windows

A **local-first, explainable Windows-to-Linux migration advisor**. It helps people evaluate software, hardware, distro fit and migration readiness before they remove anything from their current system.

The public **0.3.0** release runs without accounts, backend analytics or telemetry and keeps the decision model inspectable instead of reducing migration to a mystery percentage.

[Open the app](https://www.dennishilk.com/linux-migration-companion/) · [Repository](https://github.com/dennishilk/linux-migration-companion)
